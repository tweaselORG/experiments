# Generic web no-interaction and monkey traffic collection with persistent browser data April 2026

Issue thread: https://github.com/tweaselORG/experiments/issues/5

Scripts:

* `run.ts`: Run an analysis. Traffic is stored in `*.har`, additional metadata in `*-meta.json`.
* `export-to-database.ts`: Export the results to an SQLite database for data.tweasel.org.
